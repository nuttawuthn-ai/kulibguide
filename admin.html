เข้าสู่หน้าแอดมิน

ใส่ PIN เพื่อแก้ไขข้อมูลการนำชม การแก้ไขจะแสดงบนเว็บนำชมทันทีหลังบันทึก

ยังไม่ได้เชื่อมต่อ API ใส่ URL ของ Apps Script ในไฟล์ config.js ก่อนจึงจะบันทึกได้ ระหว่างนี้ทดลองแก้ไข ดูตัวอย่าง และดาวน์โหลดไฟล์สำรองได้
พบงานที่แก้ค้างไว้และยังไม่ได้บันทึกจากครั้งก่อน
