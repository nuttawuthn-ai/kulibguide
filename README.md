# KU Library Tour Guide

ระบบช่วยนำชม สำนักหอสมุด และหอประวัติ มหาวิทยาลัยเกษตรศาสตร์
เลือก **กลุ่มผู้เยี่ยมชม** (นิสิต ป.ตรี / ผู้บริหาร อาจารย์ นิสิต ป.โท-เอก) และ **เวลา** (20 / 30 / 40 นาที)
แล้วระบบจะแนะนำเส้นทางและบทนำชมที่เหมาะสมทันที

## ฟังก์ชัน
- จับคู่กลุ่มผู้เยี่ยมชม × เวลา → เส้นทางนำชม พร้อมเวลาแต่ละจุด (คำนวณตามเวลาเริ่มนำชม)
- บทพูดและประเด็นที่ควรเน้นแยกตามกลุ่ม + เคล็ดลับสำหรับผู้นำชม
- **โหมดนำชม** เต็มจอ: นับถอยหลังทีละจุด แจ้งเมื่อเกินเวลา ปุ่มถัดไป/ย้อนกลับ/พัก และกันหน้าจอดับ (ถ้าเบราว์เซอร์รองรับ)
- พิมพ์ / บันทึกเป็น PDF เป็นเอกสารบทนำชม
- คัดลอกลิงก์ของบทนำชม (เช่น `?g=exec&t=40`) เพื่อส่งให้ทีม
- ออกแบบสำหรับมือถือและแท็บเล็ต: ปุ่มเริ่มนำชมติดด้านล่างจอ บทพูดพับ/กางได้ ปัดซ้าย-ขวาเพื่อเปลี่ยนจุด ปรับขนาดตัวอักษร (Aa) ได้ 3 ระดับ
- ติดตั้งลงหน้าจอหลัก (Add to Home Screen) ได้ทั้ง iPhone/iPad และ Android และเปิดใช้งานได้แม้อินเทอร์เน็ตในอาคารไม่ดี (ออฟไลน์)

## แก้ไขเนื้อหา: หน้าแอดมิน (`admin.html`)
เปิด `https://<เว็บไซต์>/admin.html` แล้วใส่ PIN แก้ได้ทุกอย่างโดยไม่ต้องแตะโค้ด
- **สถานที่**: สำนักหอสมุด และหอประวัติ มก. แต่ละแห่งมีจุดนำชม เส้นทาง และเวลาของตัวเอง เปิด/ปิดการแสดงบนเว็บนำชมได้ ผู้นำชมเลือกนำชมแห่งเดียว หรือต่อเนื่องสองแห่ง (ระบบแทรกช่วงเดินทางโดยรถให้อัตโนมัติ)
- **จุดนำชม**: ชื่อ อาคาร/ชั้น บทพูดไทย-อังกฤษ ตัวเลขสำคัญ หมายเหตุ ประเด็นเน้นแยกตามกลุ่ม ลิงก์ เพิ่ม/ลบ/ทำสำเนา/สลับลำดับ
- **เส้นทาง**: ตารางแบบเดียวกับตาราง ✓ ในสคริปต์ ใส่จำนวนนาทีในช่องของจุดที่แวะ แถวล่างสุดรวมเวลาให้อัตโนมัติ
- **กลุ่มผู้เยี่ยมชม**, **เวลานำชม** (เพิ่ม/ลบได้) และ **เช็กลิสต์เตรียมก่อนนำชม**
- ตรวจข้อมูลก่อนบันทึก (เช่น เวลารวมไม่ตรง จุดที่ไม่มีบทพูด) · ดูตัวอย่างก่อนเผยแพร่
- บันทึกแล้วเว็บนำชมใช้ข้อมูลใหม่ทันที · มีประวัติทุกฉบับ กู้คืนได้ · กันบันทึกทับกันเมื่อแก้พร้อมกันหลายคน
- ดาวน์โหลด/นำเข้าไฟล์สำรอง (.json)

ข้อมูลเก็บใน Google Sheet ผ่าน Apps Script ([`apps-script/Code.gs`](apps-script/Code.gs)) ตรวจ PIN ที่ฝั่ง Apps Script (PIN ไม่อยู่ในโค้ดเว็บ) ใส่ผิด 5 ครั้งล็อก 10 นาที

เว็บนำชมโหลดข้อมูลตามลำดับ: สำเนาในเครื่อง (เปิดได้ทันที/ออฟไลน์) → ข้อมูลล่าสุดจาก Apps Script → ถ้าไม่มีทั้งสองอย่างใช้ข้อมูลตั้งต้นใน [`data.js`](data.js)

### ตั้งค่าครั้งแรก (ทำครั้งเดียว)
1. สร้าง Google Sheet ใหม่ → **Extensions → Apps Script** → ลบโค้ดเดิม วางโค้ดจาก `apps-script/Code.gs` → Save
2. ตั้ง PIN: ใส่ PIN (ตัวเลข 4–12 หลัก) ในบรรทัด `const NEW_PIN = ''` → เลือกฟังก์ชัน `setPin` → **Run** → Allow สิทธิ์ → ลบ PIN ออกจากบรรทัดนั้น → Save
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone** → Deploy → คัดลอก URL ที่ลงท้ายด้วย `/exec`
4. ใส่ URL ใน [`config.js`](config.js) (`apiUrl: "https://script.google.com/macros/s/…/exec"`) แล้ว push ขึ้น GitHub
5. เปิด `admin.html` ใส่ PIN → กด **บันทึก** ครั้งแรก (ข้อมูลตั้งต้นจากสคริปต์ rev2 จะถูกเก็บเป็นฉบับแรก)

> เปลี่ยน PIN: ทำข้อ 2 ซ้ำ ไม่ต้อง Deploy ใหม่ · แก้โค้ด Apps Script: Deploy → Manage deployments → Edit → New version (URL เดิมยังใช้ได้)

### โครงสร้างไฟล์
- `index.html` `app.js` `styles.css`: เว็บนำชม
- `admin.html` `admin.js` `admin.css`: หน้าแอดมิน
- `content.js`: โหลด/ตรวจ/แปลงข้อมูล ใช้ร่วมกันทั้งสองหน้า
- `data.js`: ข้อมูลตั้งต้น (สำรอง) จากสคริปต์นำชม 40 นาที rev2
- `config.js`: URL ของ Apps Script

## เผยแพร่บน GitHub Pages
เป็นเว็บแบบ static (HTML/CSS/JS) ไม่ต้อง build
1. push ขึ้น GitHub ที่ branch `main`
2. ไปที่ **Settings → Pages → Source** เลือก **GitHub Actions**
3. workflow ใน `.github/workflows/pages.yml` จะ deploy ให้อัตโนมัติทุกครั้งที่ push
