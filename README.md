# KU Library Tour Guide

ระบบช่วยนำชม สำนักหอสมุด มหาวิทยาลัยเกษตรศาสตร์
เลือก **กลุ่มผู้เยี่ยมชม** (ผู้บริหาร / นิสิต-นักศึกษา / ประชาชนทั่วไป) และ **เวลา** (15 / 30 / 45 / 60 นาที)
แล้วระบบจะแนะนำเส้นทางและบทนำชมที่เหมาะสมทันที

## ฟังก์ชัน
- จับคู่กลุ่มผู้เยี่ยมชม × เวลา → เส้นทางนำชม พร้อมเวลาแต่ละจุด (คำนวณตามเวลาเริ่มนำชม)
- บทพูดและประเด็นที่ควรเน้นแยกตามกลุ่ม + เคล็ดลับสำหรับผู้นำชม
- **โหมดนำชม** เต็มจอ: นับถอยหลังทีละจุด แจ้งเมื่อเกินเวลา ปุ่มถัดไป/ย้อนกลับ/พัก และกันหน้าจอดับ (ถ้าเบราว์เซอร์รองรับ)
- พิมพ์ / บันทึกเป็น PDF เป็นเอกสารบทนำชม
- คัดลอกลิงก์ของบทนำชม (เช่น `?g=exec&t=30`) เพื่อส่งให้ทีม
- รองรับมือถือ แท็บเล็ต และเพิ่มลงหน้าจอหลักได้ (PWA)

## แก้ไขเนื้อหา
แก้ได้ที่ไฟล์ [`data.js`](data.js) ไฟล์เดียว
- `STOPS` ชื่อจุด ชั้น บทพูด และประเด็นของแต่ละกลุ่ม
- `ROUTES` เส้นทางของแต่ละกลุ่ม × เวลา ในรูป `[รหัสจุด, นาที]` (ผลรวมนาทีควรเท่ากับเวลานำชม)

> ชื่อห้อง/ชั้น และบทพูดในเวอร์ชันนี้เป็นร่างตัวอย่าง กรุณาตรวจสอบให้ตรงกับพื้นที่และข้อมูลจริงของสำนักหอสมุด

## เผยแพร่บน GitHub Pages
เป็นเว็บแบบ static (HTML/CSS/JS) ไม่ต้อง build
1. push ขึ้น GitHub ที่ branch `main`
2. ไปที่ **Settings → Pages → Source** เลือก **GitHub Actions**
3. workflow ใน `.github/workflows/pages.yml` จะ deploy ให้อัตโนมัติทุกครั้งที่ push
